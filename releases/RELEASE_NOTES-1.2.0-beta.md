# Cohesix 1.2.0-beta candidate

This candidate is under M28g implementation and has no release acceptance or
publication approval. The previous [1.1.0-beta notes](RELEASE_NOTES-1.1.0-beta.md)
remain the public release record.

The selected component source adds CUDA and PEFT job workflows, native Mac MLX
work, MCP and A2A projections, and a pinned NeMo Toolkit integration. Their
component records are linked from the [build plan](../docs/BUILD_PLAN.md#28).
Native Mac and Ubuntu ARM64 installers, cross-client as-built parity, clean
installation, QEMU and Pi 4 integrated qualification, measured adoption and
release-owner approval are still required before these notes can describe an
accepted Release B. Component evidence keeps its original source and target
scope until those assembled checks pass.
